# Mini Orbi

Hand-tuned artwork at 16, 32, and 64 pixels.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<div class="icon-row"><canvas class="mini" data-size="16" width="16" height="16" aria-label="Orbi at 16 pixels"></canvas><canvas class="mini" data-size="32" width="32" height="32" aria-label="Orbi at 32 pixels"></canvas><canvas class="mini" data-size="64" width="64" height="64" aria-label="Orbi at 64 pixels"></canvas></div>
```
