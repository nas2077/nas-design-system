# Orbi

A deterministic pixel mascot with poses, gestures, dragging, and secrets.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<canvas id="component-orbi" width="56" height="46" aria-label="Interactive Orbi mascot" tabindex="0"></canvas>
```
