# Switch

A native checkbox with a tactile visual track.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<label class="n-switch"><input type="checkbox" checked><span class="n-switch__track" aria-hidden="true"></span>Keep drafts</label>
```
