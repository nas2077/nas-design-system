# Field

Recessed input surfaces with a visible label and keyboard focus.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<label class="n-field">Project name<input placeholder="Choose a name"><span class="n-field__help">Used in the page title.</span></label>
```
