# Card

Content panels use the canvas color and a shallow edge.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<div class="n-card"><strong class="n-item">A place for content.</strong><p class="n-small">Clear hierarchy, without a decorative border.</p></div>
```
