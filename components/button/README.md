# Button

Raised controls for the primary action and secondary actions.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<button class="n-button" data-n-toast="Saved">Save</button> <button class="n-button n-button--secondary">Cancel</button> <button class="n-button" disabled>Unavailable</button>
```
