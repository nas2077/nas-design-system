# Signature

The N identifies Nas as the author; it is not a product logo.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<img src="assets/signature/signature-n.svg" alt="Nas signature" width="104" height="72">
```
