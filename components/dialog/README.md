# Dialog

A native modal restores focus to its trigger when dismissed.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<button class="n-button n-button--secondary" data-n-open="example-dialog">Open dialog</button><dialog class="n-dialog" id="example-dialog"><h3 class="n-title">Ready to continue?</h3><p>Your current settings stay in place.</p><div class="n-dialog__actions"><button class="n-button n-button--secondary" data-n-close>Close</button></div></dialog>
```
