# Accordion

Native disclosure with the shared visual hierarchy.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<details class="n-accordion"><summary>What is included?</summary><div class="n-accordion__content">Tokens, components, pixel artwork, and the Orbi engine.</div></details>
```
