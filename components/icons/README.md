# Icons

Small pixel symbols use whole-number scaling.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<div class="icon-row"><img src="assets/icons/bell.svg" width="48" height="48" alt="Bell"><img src="assets/icons/lock.svg" width="48" height="48" alt="Lock"><img src="assets/icons/moon.svg" width="48" height="48" alt="Moon"><img src="assets/icons/sun.svg" width="48" height="48" alt="Sun"><img src="assets/icons/terminal.svg" width="48" height="48" alt="Terminal"></div>
```
