# Header

A short project name, one description, and a small action group.

Load `kit/nas.css` and `kit/nas.js`. Orbi examples also require `kit/orbi.js` and mini icons require `kit/orbi-icons.js`.

```html
<header class="n-header"><div><strong class="n-header__name">Project.</strong><p class="n-header__description">One clear purpose.</p></div><div class="n-header__actions"><button class="n-button n-button--small">Start</button></div></header>
```
